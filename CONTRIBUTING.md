# Contributing to Cipher Breach (PUZZLE-2-)

This browser-based five-level mission uses Caesar cipher puzzles, an interactive decoder wheel, hints, and locally saved progress.

## Clone and run
```bash
git clone https://github.com/joshuaarao42-arch/PUZZLE-2-.git
cd PUZZLE-2-
```
Open `index.html` in a modern browser.

## Project-specific contributions
- Five-level mission flow and progressive puzzle difficulty.
- Caesar cipher logic and SVG decoder wheel interactions.
- Hints, terminal feedback, and answer validation.
- Local Storage progress, reset behavior, and keyboard controls.
- Responsive layout and visual effects.

## Gameplay checks
Play all five levels. Test alphabet wraparound, keyboard arrows, hint display, copy-cipher, progress persistence after refresh, and mission reset. Verify that success and failure messages match the result. Check desktop and mobile layouts.

Use branches such as `feature/level-hints` or `fix/progress-reset`. Include the level and interactions tested, plus screenshots for visual changes.
